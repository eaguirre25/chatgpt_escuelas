# IA predominante y NBI por radio censal — General San Martín

Mapa interactivo 3D que cruza respuestas de una encuesta a estudiantes con radios censales 2022 y NBI.

## Lectura

- **Altura de cada radio**: cantidad de estudiantes encuestados georreferenciados que caen dentro del radio.
- **Color del radio**: porcentaje de hogares con NBI (Censo 2022).
- **Etiqueta**: IA predominante entre estudiantes del radio.
- **Puntos azules**: respondentes.
- **Puntos cian**: dos escuelas de referencia, sin nombre.

## Datos incluidos

- 61 respuestas completas.
- 60 respuestas completas con coordenadas.
- 50 respuestas dentro de General San Martín.
- 30 radios censales con al menos una respuesta.
- 524 radios censales del partido.

## Publicación

El repositorio es una app estática. Para publicarla con GitHub Pages:

1. Settings → Pages.
2. Source: **Deploy from a branch**.
3. Branch: **main** / **root**.
4. Guardar.

## Tecnologías

MapLibre GL JS, OpenStreetMap/CARTO y GeoJSON.
